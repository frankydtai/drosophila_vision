🎯 核心问题解答
================================================================================

问题 1: 怎么用 FlyWire 数据替代的？
答案: CSV → 加载过滤 → JSON 转换 → Flyvis 连接组类
详见: ANSWERS.md 第 1 部分

问题 2: 为什么只用了 146/741 种细胞类型？
答案: 4 层过滤（子系统、侧别、突触阈值、空间信息）
      可轻松扩展到更多数据
详见: ANSWERS.md 第 2 部分

问题 3: FlyWire 真实位置怎么对应 hex 网格？
答案: FlyWire 已提供 (p, q) 六边形坐标
      直接对应 Flyvis (u, v)，无需转换！
详见: ANSWERS.md 第 3 部分

📊 数据统计
================================================================================

FlyWire 原始数据:
  • 视觉神经元: 95,079 个
  • 细胞类型: 741 种
  • 有列分配: 45,528 个 (48%)

当前使用数据:
  • 神经元: 25,732 个（右侧视觉系统）
  • 细胞类型: 146 种
  • 连接: 2,071 个（>10 突触）
  • 有空间偏移: 119 个 (5.7%)
  • 兴奋性连接: ~90%
  • 抑制性连接: ~10%

================================================================================
🔑 关键技术亮点
================================================================================

1. 六边形坐标系统
   • FlyWire 提供 (p, q) 六边形坐标
   • 直接对应 Flyvis (u, v) 坐标
   • 无需复杂的坐标转换

2. 神经递质映射
   • ACH/GLUT → +1 (兴奋性)
   • GABA → -1 (抑制性)
   • 自动推断突触符号

3. 完全兼容 Flyvis
   • 使用 @register_connectome 自动注册
   • 与原始 Flyvis 接口完全相同
   • 可直接替换原始连接组

4. 可扩展性
   • 修改过滤参数即可包含更多数据
   • 支持 300+ 种细胞类型
   • 可使用全部 741 种细胞类型
