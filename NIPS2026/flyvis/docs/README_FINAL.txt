================================================================================
  🔑 关键技术亮点
================================================================================

1. 六边形坐标系统
   • FlyWire 提供 (p, q) 六边形坐标
   • 直接对应 Flyvis (u, v) 坐标
   • 无需复杂的坐标转换！

2. 神经递质映射
   • ACH/GLUT → +1 (兴奋性)
   • GABA → -1 (抑制性)
   • 自动推断突触符号

3. 完全兼容 Flyvis
   • 使用 @register_connectome 自动注册
   • 与原始 Flyvis 接口完全相同
   • 可以直接替换原始连接组
