## 项目背景

### 什么是这个项目？
我们正在构建一个基于果蝇全脑连接组的闭环控制系统，目标是：
- 使用真实的果蝇大脑连接数据
- 用DMN神经网络模型模拟神经活动
- 在NeuroMechFly物理模拟器中控制虚拟果蝇
- 实现视觉输入→神经处理→行为输出的完整闭环

### 为什么做这个项目？
- **科学价值**: 理解大脑如何控制行为
- **技术创新**: 结合真实连接组和深度学习
- **领域机会**: 这是一个新兴领域，竞争相对较少
- **发表目标**: 投稿NeurIPS 2026顶级会议

### 我们的优势
- 有完整的果蝇连接组数据(FlyWire)
- 有现成的模型可以参考(RF, DMN)
- 有丰富的行为数据
- 团队成员互补

## 关键概念

### 1. 果蝇连接组 (Connectome)
- **定义**: 果蝇大脑中所有神经元及其连接的完整地图
- **数据**: FlyWire FAFB v783，包含139,255个神经元
- **用途**: 提供真实的大脑网络结构

### 2. DMN模型
- **全称**: Connectome-constrained networks
- **特点**: 基于真实连接组，有可学习的突触参数
- **输入**: 视频/视觉刺激
- **输出**: 神经元激活模式

### 3. NeuroMechFly
- **定义**: 果蝇的物理模拟模型
- **引擎**: MuJoCo物理引擎
- **功能**: 模拟果蝇的运动和行为
- **输入**: 肌肉控制信号
- **输出**: 果蝇行为(位置、姿态等)

### 4. 闭环系统
```
视觉输入 → DMN模型 → 神经激活 → 肌肉信号 → NeuroMechFly → 行为输出
    ↑                                                              ↓
    └──────────────────── 感觉反馈 ←──────────────────────────────┘
```

## 附录：术语表

- **Connectome**: 连接组，神经系统的完整连接图谱
- **FlyWire**: 果蝇全脑连接组项目
- **FAFB**: Female Adult Fly Brain，成年雌性果蝇大脑
- **DMN**: Connectome-constrained networks，基于连接组的神经网络
- **RF Model**: Receptive Field Model，感受野模型
- **MuJoCo**: Multi-Joint dynamics with Contact，物理引擎
- **NeuroMechFly**: 果蝇神经机械模型
- **Synapse**: 突触，神经元之间的连接
- **Neurotransmitter**: 神经递质，神经元通讯的化学物质
- **Optic Lobe**: 视叶，果蝇视觉处理区域
- **Motor Neuron**: 运动神经元，控制肌肉的神经元
- **Closed-loop**: 闭环，有反馈的控制系统
- **NeurIPS**: Neural Information Processing Systems，顶级AI会议
