# 训练策略总结 - 快速参考

## 🎯 核心问题回答

### Q1: 如何利用behavior数据和视觉输入训练？

**答案**: 端到端的监督学习 + 闭环强化学习

```
视觉输入 (从其他果蝇3D pose生成)
    ↓
DMN模型 (基于FlyWire连接组)
    ↓
肌肉控制信号
    ↓
NeuroMechFly模拟
    ↓
预测的行为 → 与真实行为数据对比 → 计算损失 → 反向传播
```

---

### Q2: 哪些参数需要训练？

#### 必须训练的参数 ⭐⭐⭐
1. **突触权重** (Synaptic Weights)
   - 连接拓扑固定（来自FlyWire）
   - 但权重强度需要学习
   - 这是最重要的参数

2. **运动解码器** (Motor Decoder)
   - 神经元激活 → 肌肉信号的映射
   - 线性或非线性变换

#### 可选训练的参数 ⭐⭐
3. **视觉编码器** (Visual Encoder)
   - 视觉输入 → 视觉神经元激活
   - 感受野参数

4. **神经递质参数**
   - 释放概率
   - 时间常数

#### 建议固定的参数 ⭐
5. **神经元模型参数**
   - 如果太复杂会难以训练
   - 建议使用简单的LIF或rate-based模型

### Q3: 最终目标是什么？

#### 短期目标 (NeurIPS 2026) 📅

**定量指标**:
- ✅ 关键点位置误差 < 5mm
- ✅ 能预测未来0.5-1秒的行为
- ✅ 闭环运行10秒以上不发散

**定性指标**:
- ✅ 行为看起来自然
- ✅ 符合物理规律
- ✅ 优于baseline (RF Model)

#### 长期目标 (后续研究) 🚀
- 完整的社交行为模拟
- 理解神经机制
- 发现关键神经回路

## 🔑 关键技术点

### 1. 视觉输入生成
```python
# 从social behavior生成单只果蝇的视觉输入
def generate_visual_input(scene, focal_fly):
    # 1. 获取其他果蝇的3D poses
    other_flies = get_other_flies(scene, focal_fly)
    
    # 2. 从focal fly的视角渲染
    visual_input = render_from_fly_perspective(
        other_flies, 
        focal_fly.position,
        focal_fly.orientation
    )
    
    return visual_input
```

### 2. 损失函数
```python
# 多目标损失函数
L_total = (
    1.0 * L_keypoint +      # 位置误差
    0.5 * L_velocity +      # 速度误差
    0.2 * L_acceleration +  # 加速度误差
    0.3 * L_physics +       # 物理约束
    0.1 * L_neural          # 神经约束
)
```

### 3. 训练技巧
- 梯度裁剪（防止爆炸）
- 学习率调度（逐渐降低）
- 分阶段训练（从简单到复杂）
- 数据增强（不同视角、速度）

## ⚠️ 主要挑战

### 挑战1: 计算复杂度
**解决**: 只用相关神经元子集（~1000-5000个）

### 挑战2: 训练不稳定
**解决**: 分阶段训练 + 梯度裁剪

### 挑战3: 数据对齐
**解决**: 仔细的时间戳对齐

### 挑战4: 评估困难
**解决**: 多个定量指标 + 人工评估

## 📈 评估指标

### 行为重构
- MPJPE (Mean Per Joint Position Error)
- 不同身体部位的误差
- 轨迹相似度

### 运动质量
- 平滑性（jerk）
- 物理可行性
- 自然度评分

### 神经活动
- 激活率
- 稀疏性
- 与生理数据一致性
