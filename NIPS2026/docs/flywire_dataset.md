   Connections (Filtered) (68 MB)   
Description
Filtered synaptic connectivity table (5+ synapse threshold). One row for every connected pair of cells and neuropil (region). First and second columns contain the FlyWire Root IDs of the connected pair ('pre/from' and 'post/to' respectively), the third column contains the neuropil abbreviation, the fourth contains the number of synapses (aggregated across all connection sites of the respective pair and neuropil), and the fifth column contains the predicted NT type for the synapses. Notes: Connections with fewer than 5 total synapses (across all neuropils) are excluded, along with autapses. More than one row can be present for the same pair of cells if they synapse in multiple neuropils (regions).
Unprocessed connectivity data for certain FlyWire snapshots is available on Zenodo as well.

Note on data versioning and consistency
The files available for download on this portal are synchronized with the live Codex database and represent the most up-to-date version of the dataset. They are continually updated and curated from multiple sources, including papers published both alongside and independently of the original FlyWire package. As a result, the content of these files may differ from the static snapshot released at the time of the FlyWire package publication in October 2024. To access the original dataset as published in October 2024 instead, please refer to the following links:

Zenodo archive for FlyWire connectivity data from Dorkenwald et al., 2024
GitHub repo with FlyWire annotations from Schlegel et al., 2024
Zenodo archive for Supplemental data from Schlegel et al., 2024
GitHub repo with FlyWire visual system cell types from Matsliah et al., 2024
