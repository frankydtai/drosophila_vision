**问题**：
- ❌ 删除节点时**不调整半径**
- ❌ 总表面积会减少
- ❌ 电容会减少
- ❌ 不适合电生理模拟

#### 改进版本
```python
def simplify_collinear_nodes(self, nodes: Dict) -> Tuple[Dict, int]:
    while True:
        # ... 相同的拓扑检测 ...
        
        if cos_angle <= cos_limit:
            # 计算物理量保留的等效半径
            r1 = nodes[pid]['r']
            r2 = node['r']
            L1 = len1
            L2 = len2
            
            # 长度加权平均半径（保留表面积）
            r_eq = (r1 * L1 + r2 * L2) / (L1 + L2)
            
            # 更新子节点半径
            nodes[cid]['r'] = r_eq  # 关键改进！
            nodes[cid]['parent'] = pid
            del nodes[nid]
```

**改进**：
- ✅ 计算等效半径
- ✅ 保留总表面积
- ✅ 保留膜电容
- ✅ 适合电生理模拟

**数学验证**：
```
原始: A1 + A2 = 2πr1L1 + 2πr2L2
等效: A_eq = 2πr_eq(L1+L2) = 2π[(r1L1+r2L2)/(L1+L2)](L1+L2) = 2π(r1L1+r2L2) ✓
```

```python
def compute_surface_area(self, nodes: Dict) -> float:
    """
    计算神经元的总表面积
    使用圆柱体表面积公式: A = 2πrL
    """
    total_area = 0.0
    for nid, node in nodes.items():
        pid = node['parent']
        if pid != -1 and pid in nodes:
            length = self.compute_distance(node, nodes[pid])
            radius = node['r']
            area = 2 * math.pi * radius * length
            total_area += area
    return total_area
```

**用途**：
- ✅ 验证物理量保留
- ✅ 评估简化质量
- ✅ 与Jaxley计算一致
