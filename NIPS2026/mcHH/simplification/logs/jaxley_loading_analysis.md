## 1. 简化后SWC能否被Jaxley正确加载？

### 1.1 Jaxley的SWC加载流程

```
read_swc(fname, ncomp)
  → to_swc_graph(fname)           # 读取SWC → NetworkX有向图
    → np.loadtxt(fname)           # ← 这里是关键入口
    → graph.add_nodes_from(...)   # id, x, y, z, r, p 作为节点属性
    → graph.add_edges_from(...)   # parent→child 边
    → _add_missing_graph_attrs()  # 补充缺失属性，计算边长
    → _add_edge_lengths()         # L = sqrt(dx²+dy²+dz²), 最小1e-5
  → build_compartment_graph(swc_graph, ncomp)
    → _trace_branches()           # DFS遍历，识别分支和分支点
    → 对每个branch做compartmentalization
    → 计算 radius, area, volume, resistive_load
  → from_graph(comp_graph)        # 转换为 jx.Cell
```

### 1.2 潜在报错点分析

#### ⚠️ 问题1: `np.loadtxt` 要求纯数字

```python
# Jaxley源码 (graph.py:121)
i_id_xyzr_p = np.loadtxt(fname)[:num_lines]
```

**风险**: `np.loadtxt` 会自动跳过 `#` 开头的注释行。我们的SWC文件有注释头：
```
# Simplified neuron morphology
# Generated by NeuronSimplifier with physics preservation
# Format: id type x y z radius parent
1 1 0.000000 0.000000 0.000000 2.500000 -1
```

**结论**: ✅ **安全** — `np.loadtxt` 默认跳过 `#` 注释。

#### ⚠️ 问题2: 节点ID必须从小到大且作为第一列

```python
# graph.py:124-130
graph.add_nodes_from(
    (int(i), {"id": int(id), "x": x, "y": y, "z": z, "r": r, "p": int(p)})
    for i, id, x, y, z, r, p in i_id_xyzr_p
)
graph.add_edges_from([(p, i) for p, i in i_id_xyzr_p[:, [-1, 0]] if p != -1])
```

**风险**: 我们简化后ID可能不连续（例如 1, 3, 7, 15...），因为删除了中间节点。

**结论**: ✅ **安全** — Jaxley用 `int(i)` 作为graph节点键，不要求连续。NetworkX支持任意整数键。边也通过 parent_id→node_id 添加，只要parent_id在图中存在即可。

#### ⚠️ 问题3: `_add_missing_graph_attrs` 假定节点1存在

```python
# graph.py:149
available_keys = graph.nodes[1].keys()
```

**风险**: 如果简化后删除了节点1，这里会 `KeyError`！

**结论**: ❌ **可能报错！** — 如果节点1（通常是根节点/soma）被删除。但实际上我们的简化器保证根节点不被删除，而SWC的根节点通常ID=1。不过如果原始SWC的根节点不是ID=1（有些文件从其他ID开始），可能出问题。

**修复方案**: 在 `write_swc` 时重新编号，确保ID从1开始连续。

#### ⚠️ 问题4: 森林结构（多棵树）

简化后的`prune_tree`可能导致一些孤立子树（parent被设为-1但原来不是根）。

```python
# 在prune_tree中:
if pid not in new_nodes:
    node["parent"] = -1  # 变成多个根！
```

**风险**: Jaxley假设SWC是单棵树（一个根）。多个根会导致遍历不完整。

**结论**: ❌ **可能报错！** — 需要确保输出是连通树。

**修复方案**: 需要重新连接断开的子树到最近的保留节点。

#### ⚠️ 问题5: 表面积计算方式不同

Jaxley使用**截锥体**(truncated cone)近似，不是简单的圆柱体：

```python
# morph_attributes.py - swc_area()
frustum_surface_areas = π * (r_start + r_end) * slant_length
# 其中 slant_length = sqrt(Δr² + L²)
```

而我们的简化器假设圆柱体:
```python
A = 2πrL
```

**结论**: ⚠️ **微小差异** — 当相邻节点半径差别很大时，截锥体面积 ≠ 圆柱体面积。但对于我们长度加权平均后的半径，这个差异通常很小。

#### ⚠️ 问题6: 单点分支处理

```python
# morph_attributes.py 
if len(xyzr) == 1:
    # 球体近似
    total_surface_area = 4 * π * r² / ncomp
    total_volume = 4/3 * π * r³ / ncomp
```

如果简化后某个分支只剩一个点（可能在极端剪枝后），Jaxley会用球体近似处理。

**结论**: ✅ **安全** — Jaxley有处理逻辑。

### 1.3 总结：加载风险评级

| 问题 | 风险 | 严重性 | 需要修复 |
|-----|------|--------|---------|
| 注释行 | ✅ 安全 | - | 否 |
| 不连续ID | ✅ 安全 | - | 否，但建议重编号 |
| 节点1不存在 | ❌ 可能报错 | 高 | **是** |
| 多棵树 | ❌ 可能报错 | 高 | **是** |
| 面积计算差异 | ⚠️ 微小 | 低 | 可选 |
| 单点分支 | ✅ 安全 | - | 否 |

### 1.4 必须的修复

```python
def write_swc_jaxley_compatible(nodes, out_path):
    """输出Jaxley兼容的SWC（重新编号，确保连通树）"""
    # 1. 确保只有一个根
    roots = [nid for nid, n in nodes.items() if n['parent'] == -1]
    if len(roots) > 1:
        # 连接所有子树到第一个根
        main_root = roots[0]
        for extra_root in roots[1:]:
            nodes[extra_root]['parent'] = main_root
    
    # 2. 重新编号，从1开始连续
    old_ids = sorted(nodes.keys())
    id_map = {old: new for new, old in enumerate(old_ids, start=1)}
    
    with open(out_path, 'w') as f:
        f.write("# Simplified neuron for Jaxley\n")
        for old_id in old_ids:
            n = nodes[old_id]
            new_id = id_map[old_id]
            new_parent = id_map.get(n['parent'], -1) if n['parent'] != -1 else -1
            f.write(f"{new_id} {n['type']} {n['x']:.6f} {n['y']:.6f} "
                   f"{n['z']:.6f} {n['r']:.6f} {new_parent}\n")
```

## 2. Jaxley的电压模拟数学原理

### 2.1 Cable Equation (电缆方程)

Jaxley的核心是求解**分支电缆方程**：

$$C_m \frac{\partial V}{\partial t} = \frac{1}{2 R_a r} \frac{\partial}{\partial x} \left( r^2 \frac{\partial V}{\partial x} \right) - \sum_k g_k (V - E_k) + I_{ext}$$

离散化后，对compartment i：

$$C_m \cdot A_i \cdot \frac{dV_i}{dt} = \sum_{j \in \text{neighbors}} G_{ij}^{axial} (V_j - V_i) - \sum_k g_k \cdot A_i \cdot (V_i - E_k) + I_{ext,i}$$

### 2.2 轴向电导 (Axial Conductance)

两个相邻compartment i,j 之间的轴向电导：

$$G_{ij}^{axial} = \frac{1}{R_a \cdot (r_{load,i}^{out} + r_{load,j}^{in})}$$

其中 resistive load（电阻负载）：

$$r_{load} = \frac{1}{\pi} \int \frac{1}{r^2} dl$$

对于恒定半径的compartment: $r_{load} = \frac{L}{r^2 \pi}$

### 2.3 Jaxley的求解方法

Jaxley将方程写成矩阵形式：

$$\frac{V^{n+1} - V^n}{\Delta t} = \mathbf{G} \cdot V^{n+1} + \mathbf{I}_{channel}(V^n)$$

即：

$$(I - \Delta t \cdot \mathbf{G}) V^{n+1} = V^n + \Delta t \cdot \mathbf{I}_{channel}$$

其中 G 是一个准三对角矩阵（quasi-tridiagonal），用DHS算法(Dendritic Hierarchical Scheduling)求解。

### 2.4 Jaxley的Channel机制

对每个compartment，电流贡献分为：
- **voltage_terms**: V的线性部分 (∑g_k)
- **constant_terms**: 常数部分 (∑g_k·E_k + I_ext)

$$\frac{dV_i}{dt} = -\text{voltage\_terms}_i \cdot V_i + \text{constant\_terms}_i + \text{axial\_coupling}$$

## 3. PyTorch多compartment电压模拟方案

### 3.1 核心思路

将Jaxley的JAX实现移植到PyTorch，关键区别：
1. **JAX** → **PyTorch**: jnp → torch, jax.jit → torch.compile
2. **隐式求解** → **显式Euler**: 避免实现复杂的DHS算法
3. **分支树结构** → **稀疏矩阵**: 用PyTorch sparse tensor表示轴向耦合

### 3.2 架构设计

```
MultiCompartmentHH (nn.Module)
├── MorphologyGraph        # 从SWC构建compartment图
│   ├── branches           # 分支列表
│   ├── comp_edges         # compartment间的连接
│   ├── areas              # 每个compartment的表面积
│   ├── volumes            # 每个compartment的体积
│   └── axial_conductances # 轴向电导
├── HHChannels             # HH通道动力学
│   ├── gating: m, h, n
│   └── currents: I_Na, I_K, I_L
├── SynapseModel           # 突触模型
└── integrate()            # 时间积分器
```

### 3.3 关键公式 (PyTorch实现)

#### (a) 轴向耦合
```python
# 稀疏矩阵 G_axial: (n_comp, n_comp)
# G_axial[i,j] = g_ij if i,j are connected
# diagonal: G_axial[i,i] = -sum_j(g_ij)
axial_current = G_axial @ V  # (n_comp,)
```

#### (b) HH膜电流
```python
I_Na = g_Na * m**3 * h * (V - E_Na)
I_K  = g_K  * n**4 * (V - E_K)
I_L  = g_L  * (V - E_L)
I_membrane = -(I_Na + I_K + I_L)  # 进入membrane的总电流
```

#### (c) 电压更新
```python
dV/dt = (1/C_m) * (I_membrane / A + axial_current / (C_m * A) + I_ext / A)
```

标准化到每单位面积后（Jaxley的做法）：

```python
# voltage_terms = (g_Na*m³h + g_K*n⁴ + g_L) / C_m  [单位: mS/cm² / μF/cm² = 1/ms]
# constant_terms = (g_Na*m³h*E_Na + g_K*n⁴*E_K + g_L*E_L + I_ext) / C_m
# axial_terms = G_axial @ V / (C_m * A) * 1e7  [单位转换]

dV/dt = -voltage_terms * V + constant_terms + axial_terms
```

### 3.4 与现有dynamics.py的关系

现有 `dynamics.py` 的 `HHModel` 是**单compartment**的：
- 每个"节点"是一个独立的HH神经元
- 突触输入通过 `target_sum(weight * v_at_pre)` 计算
- **没有**轴向耦合（compartment间的电流传导）

新的**多compartment HH**需要：
- 一个"神经元"包含**多个compartment**
- compartment之间通过**轴向电导**耦合
- 每个compartment有独立的HH通道和门控变量
- 突触连接在**特定compartment**上

### 4.2 阶段2: PyTorch HH模型

```python
class MultiCompartmentHH(nn.Module):
    def __init__(self, morph: MorphologyGraph):
        self.n_comp = morph.n_comp
        self.G_axial = morph.G_axial_sparse  # 稀疏矩阵
        self.areas = morph.areas              # (n_comp,)
        self.C_m = nn.Parameter(...)          # 可学习
        
    def step(self, state, I_ext, dt):
        V, m, h, n = state['V'], state['m'], state['h'], state['n']
        
        # 1. 通道电流
        I_Na, I_K, I_L = self.channel_currents(V, m, h, n)
        
        # 2. 轴向耦合
        I_axial = self.G_axial @ V  # 稀疏矩阵乘法
        
        # 3. 电压更新 (显式Euler或Crank-Nicolson)
        dV = (1/self.C_m) * (-(I_Na+I_K+I_L) + I_axial/(self.areas) + I_ext)
        V_new = V + dt * dV
        
        # 4. 门控变量更新
        m_new = m + dt * (alpha_m*(1-m) - beta_m*m)
        h_new = h + dt * (alpha_h*(1-h) - beta_h*h)
        n_new = n + dt * (alpha_n*(1-n) - beta_n*n)
        
        return {'V': V_new, 'm': m_new, 'h': h_new, 'n': n_new}
```

## 5. 关键挑战

### 5.1 计算效率

- 单compartment HH: 矩阵大小 (n_neurons, n_neurons)
- 多compartment HH: 矩阵大小 (n_neurons × n_comp, n_neurons × n_comp)

如果每个神经元100个compartment，1000个神经元 → 100,000维的稀疏线性系统。

**解决方案**: 
- 使用PyTorch sparse tensor
- 显式Euler（避免矩阵求逆）
- 或Crank-Nicolson + 稀疏LU分解

### 5.2 可微分性

PyTorch支持自动微分，可以训练：
- 通道最大电导 (g_Na, g_K, g_L)
- 膜电容 (C_m)
- 轴向电阻率 (R_a)
- 甚至morphology参数（半径、长度）

### 5.3 与Jaxley的一致性验证

需要在相同输入下比较PyTorch和Jaxley的输出，确保数值一致：
- 稳态电压
- 动作电位形状
- 电压衰减沿dendrite的传播
