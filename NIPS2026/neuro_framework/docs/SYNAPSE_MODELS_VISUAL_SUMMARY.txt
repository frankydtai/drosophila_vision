┌─ SYNAPSE MODELS ─────────────────────────────────────────────────────────────┐
│                                                                              │
│  1. Simple              ⚡⚡⚡⚡  [Weight-based, default]                    │
│     • No state variables                                                     │
│     • 1 parameter per edge                                                   │
│     • Fastest computation                                                    │
│                                                                              │
│  2. TanhRate            ⚡⚡⚡   [Tanh activation]                           │
│     • No state variables                                                     │
│     • 3 parameters per edge (gS, x_offset, slope)                            │
│     • Smooth activation function                                             │
│                                                                              │
│  3. TanhConductance     ⚡⚡⚡   [Conductance-based]                         │
│     • No state variables                                                     │
│     • 4 parameters per edge (gS, e_syn, x_offset, slope)                     │
│     • Includes driving force                                                 │
│                                                                              │
│  4. Ionotropic          ⚡⚡    [Biophysical]                                │
│     • 1 state variable (s - open probability)                                │
│     • 5 parameters per edge (gS, e_syn, k_minus, v_th, delta)                │
│     • Most biologically realistic                                            │
